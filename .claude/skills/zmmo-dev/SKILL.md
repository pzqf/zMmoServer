# 继续 zMmoServer 成熟化改造

本技能是一个**薄指针**。所有开发方法、验证纪律、约定、环境坑的**唯一真相源**是仓库文档，
不在本文件复制（避免多处漂移）。换任何 AI/编辑器都读同一份文档即可。

## 第一步：加载真相源

依次读取并遵循：

1. `D:\GitHub\zMmoServer\docs\开发约定与工作流.md` — **工作方法与约定的唯一真相源**（先读这份）。
2. `D:\GitHub\zMmoServer\docs\成熟化改造-执行计划.md` — 进度台账，**勾选框 = 进度真相**，从这里选下一块。
3. `D:\GitHub\zMmoServer\docs\协议契约.md` — 跨服契约（改协议前必读）。
4. 相关项目记忆（导航、决策、环境、已知坑）。

（跨工具通用入口另见仓库根 `AGENTS.md`，其同样指向上述文档。）

## 第二步：按工作环推进

严格按开发约定文档里的工作环：**勘察 → 找潜伏 bug → 修 → 加真测试 → 真 E2E → 更新台账/记忆**。
一次只做一块、做透（编译+测试+E2E+台账 全绿才开下一块）。自评不可信，每个"完成"挂一个通过的证据。

## 第三步：收尾

- `scripts/ci-check.ps1` 全模块 build+vet 绿。
- 台账勾选 + 写清证据；里程碑追加变更记录（`0.0.X`）。
- 清理临时探针；同步记忆。
