# 开发 / 改进 zMmoServer 框架本身

本技能是**薄指针**。所有开发方法、验证纪律、约定、环境坑的**唯一真相源**是仓库文档，不在本文件复制（避免漂移）。

> 与 `zmmo-game-dev` 的区别：本技能 = 改/硬化**框架本身**；`zmmo-game-dev` = 在框架上**开发游戏功能**。

## 第一步：加载真相源（按序）

1. `D:\GitHub\zMmoServer\docs\开发约定与工作流.md` — **工作方法与验证纪律的唯一真相源**（先读）。
2. `D:\GitHub\zMmoServer\docs\架构.md` — 架构心智（四进程 / realm / 权威分层 / 单写者 / AOI / 一致性）。
3. `D:\GitHub\zMmoServer\docs\协议契约.md` — 跨服契约（改协议前必读；唯一编解码源 `zCommon/crossserver/codec.go`）。
4. 相关项目记忆（导航、决策、环境、已知坑）。

（跨工具通用入口另见仓库根 `AGENTS.md`。）

## 第二步：按工作环推进

严格按开发约定文档里的工作环：**勘察 → 找潜伏 bug → 修 → 加真测试 → 真 E2E → 更新文档/记忆**。
一次只做一块、做透（编译 + 测试 + E2E 全绿才开下一块）。自评不可信，每个"完成"挂一个通过的证据。

## 第三步：收尾

- `scripts/ci-check.ps1` 全模块 build+vet 绿；并发类在有 gcc 的环境跑 `-race`。
- 清理临时探针；同步记忆与文档（改约定只改真相源那一处）。
