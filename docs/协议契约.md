# 协议契约（跨服 GameServer ↔ MapServer）

**版本**: 0.0.1
**创建**: 2026-07-23（成熟化改造 Phase 0.3）
**唯一真相源**: `zCommon/crossserver/codec.go`（收发两端必须只经此编解码）

---

## 一、为什么要有这份契约

改造前 Game↔Map 链路断裂，根因是"契约散落、各写各的"：

| 环节 | 改造前（断） | 现在（统一） |
|------|-------------|-------------|
| 外层 zNet ProtoId | GameServer 恒发 `300`；MapServer 只认 `400/402/404/406` | 统一 = InternalMsgId（请求 400/402/404/406，响应 401/403/405/407）|
| 跨服消息类型 | GameServer 用 `protocol.CrossServerMessage`(protobuf)；MapServer 用 `crossserver.CrossServerMessage`(Go结构体) | 统一 `protocol.CrossServerMessage`(protobuf) |
| 编码 | 发 protobuf / 收 JSON | **全程 protobuf，禁止 JSON** |
| 内层请求 | GameServer 用无坐标的 `ClientMapEnterRequest`；MapServer 期望带坐标的 `MapEnterRequest` | 统一 `MapEnterRequest/…`（带坐标）|
| 封装层数 | 双重 `BaseMessage` 嵌套 | 单层 |

## 二、线格式（wire format）

```
┌─────────────────────────── zNet NetPacket ───────────────────────────┐
│ Header(36B): ProtoId = InternalMsgId(400/402/404/406/401/403/405/407) │
│ Data:                                                                  │
│   ┌──────────── crossserver Envelope (40B, 大端) ────────────┐        │
│   │ Magic 0x5A4D4D4F | Ver | MsgType | TraceID | RequestID |  │        │
│   │ Timestamp | SourceServerID | SourceService | ...          │        │
│   └───────────────────────────────────────────────────────────┘        │
│   payload = proto.Marshal(protocol.CrossServerMessage{                 │
│       TraceId, FromServerId, ToServerId, FromService, ToService,       │
│       Message: BaseMessage{                                            │
│           MsgId = InternalMsgId, PlayerId, ServerId, MapId,           │
│           Data = proto.Marshal(具体业务消息)                          │
│       }                                                                │
│   })                                                                   │
└────────────────────────────────────────────────────────────────────────┘
```

**三重一致**：外层 zNet ProtoId == 内层 `BaseMessage.MsgId` == `InternalMsgId`。收发两端按同一 ID 路由。

## 三、ID 与消息对照

| 动作 | 请求 ProtoId | 请求内层消息 | 响应 ProtoId | 响应内层消息 |
|------|-------------|-------------|-------------|-------------|
| 进入地图 | `MSG_INTERNAL_MAP_ENTER_REQUEST` = 400 | `MapEnterRequest{player_id, map_id, x, y, z}` | 401 | `MapEnterResponse` |
| 离开地图 | `MSG_INTERNAL_MAP_LEAVE_REQUEST` = 402 | `MapLeaveRequest{player_id, map_id, reason}` | 403 | `MapLeaveResponse` |
| 移动 | `MSG_INTERNAL_MAP_MOVE_REQUEST` = 404 | `MapMoveRequest{player_id, object_id, map_id, x, y, z}` | 405 (`MOVE_SYNC`) | `MapMoveResponse` |
| 攻击 | `MSG_INTERNAL_MAP_ATTACK_REQUEST` = 406 | `MapAttackRequest{player_id, object_id, map_id, target_id}` | 407 (`COMBAT_ACTION`) | `MapAttackResponse{damage, target_hp, …}` |

> 注意：以上是**服务器间**协议（InternalMsgId）。客户端↔GameServer 用的是 `MapMsgId`（1200/1202/1204/1206，game.proto），两者不可混用。

### 三.1 AOI 视野回程（MapServer → GameServer，服务端主动推送，Phase 2.3）

MapServer 是地图对象权威，其 AOI 计算出的"谁看见谁进入/离开/移动视野"事件需回传给拥有观察者(watcher)的 GameServer，再由 GameServer 复用既有推送链投递客户端。protoId 常量在 `zCommon/crossserver/internal_ids.go`，承载复用现有 protobuf（免 proto 重生成）：

| 事件 | 内部 protoId | 承载内层消息 | 客户端 protoId |
|------|-------------|-------------|---------------|
| 进入视野 | `MsgInternalAOIEnter` = 500 | `EntityEnterViewNotify{entity_id, pos}` | `MSG_MAP_ENTER_VIEW` = 1220 |
| 离开视野 | `MsgInternalAOILeave` = 501 | `EntityLeaveViewNotify{entity_id}` | `MSG_MAP_LEAVE_VIEW` = 1221 |
| 视野内移动 | `MsgInternalAOIMove` = 502 | `EntityMoveNotify{entity_id, old_pos, new_pos}` | `MSG_MAP_ENTITY_MOVE` |

约定：**watcher（观察者玩家 ID）放 `BaseMessage.PlayerId`、mapID 放 `BaseMessage.MapId`、事件类型由 protoId(500/501/502) 区分**。MapServer 按 watcher 查其 GameServer 会话（`PlayerGameServerManager` + `gameServerSessions` 注册表）推送；GameServer 收后 `HandleAOINotify` → 路由 watcher 玩家 Actor → `pushToClient`（经已接受的 Gateway zNet 会话，非旧的 cm.gatewayConn）。

## 四、编解码 API（唯一入口）

```go
// zCommon/crossserver/codec.go
func BuildBaseMessage(msgID uint32, playerID uint64, serverID, mapID uint32, payload []byte) *protocol.BaseMessage
func PackMessage(meta Meta, fromService, toService uint8, fromServerID, toServerID uint32, base *protocol.BaseMessage) ([]byte, error)
func UnpackMessage(data []byte) (Meta, *protocol.CrossServerMessage, *protocol.BaseMessage, error)
```

- 请求 meta：`crossserver.NewRequestMeta(ServiceTypeGame, serverID)`
- 响应 meta：`crossserver.NewResponseMetaFromRequest(reqMeta, ServiceTypeMap, serverID)`（保持 TraceID/RequestID 以关联请求）

**禁止**在业务代码里手写 `proto.Marshal(CrossServerMessage)` / `json.Marshal` / 直接拼 Envelope——一律走上述三函数。
