# zMmoServer 文档索引

本目录同时存放**面向使用者/学习者的说明文档**与**项目演进过程中的内部工作台账**。
两类文档目的不同——前者帮你理解并使用框架，后者记录"为什么这么改、改到哪一步"。
初次接触请从仓库根目录的 [`README.md`](../README.md) 开始，再按需查下表。

## 一、面向使用者 / 学习者（推荐先读）

想理解设计、集成或扩展这套框架，读这些：

| 文档 | 讲什么 | 什么时候看 |
|------|--------|-----------|
| [架构设计方案.md](架构设计方案.md) | 分布式四层架构（Global/Gateway/Game/Map）的整体设计与分层职责 | 想搞清楚系统怎么搭起来的 |
| [通信模式设计方案.md](通信模式设计方案.md) | 网关—游戏服—地图服之间的通信模式与消息流 | 想理解请求如何在服务间流转 |
| [协议契约.md](协议契约.md) | 跨服 Game↔Map 的线格式（Envelope）与 ID 契约 | 要对接/扩展跨服消息、加新协议 |
| [规范.md](规范.md) | 统一目录结构、命名、配置规范 | 要往仓库里加代码/配置 |
| [游戏设计.md](游戏设计.md) | 游戏背景与玩法设计（业务层参考，非框架核心） | 关心承载在框架上的玩法示例 |

## 版本约定

文档与 release 采用 `0.0.X` 递增；框架成熟前不发 `1.0`。带 `**版本**:` 头的文档以其自身声明为准。
